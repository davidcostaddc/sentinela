# Sentinela

Sistema educativo de análise heurística de links e mensagens suspeitas, desenvolvido com Python e FastAPI.

## Funcionalidades

- Interface responsiva em português.
- Análise de links suspeitos.
- Análise de e-mails e mensagens.
- Identificação de indicadores de risco.
- Pontuação e classificação de risco.
- Recomendações de segurança.

## Tecnologias

- Python
- FastAPI
- HTML
- CSS
- JavaScript

## O que está incluído

- Interface responsiva em português.
- Alternância entre análise de link e e-mail.
- Integração com os endpoints FastAPI.
- Exibição da pontuação, classificação, indicadores e recomendação.
- O backend analisa o texto da URL e não visita o endereço.
